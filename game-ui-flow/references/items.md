# 物品与操作

先读统一物品目录、库存和使用规则；不在选择器另存一份名称、价格和偏好。

选择器帮助找到对象，详情帮助判断，操作区执行明确动作。小规模物品目录可集中展示；大量目录按玩家查找方式过滤或分组，不默认无限滚动，也不默认三件一页。没有需要时不添加搜索栏。

名称、图标、数量与状态按用途显示。已拥有、可购买、未解锁、已选择、已装备不是同一状态；不能都用灰色表达。选择标记应有形状、文字或其他可辨线索。未拥有物品是否可预览由游戏规则决定。

打开奖励中的“查看/使用”时携带稳定物品 ID，而非只打开物品所属页面。正确恢复角色或部位，不能让用户看到上一次浏览的另一件东西。物品已消耗或不可用时解释当前状态，不凭旧画面再次使用。

预览通常不保存装备；购买先入库或直接装备由项目规则决定，按钮需准确说明。赠送选择目标、数量与收益后，使用已有一致交易入口；显示成功必须来自真实结果。重复请求、余额不足和页面离开等错误处理沿用领域规则，不由 UI 再实现一套经济系统。

筛选可以不改变选中项。关闭取消是否保留尚未确认的预览，要与产品任务一致。不要让翻页、切筛选或滚动顺便执行“选中第一项”，除非这是已说明的交互规则。

空库存、无筛选结果、禁用操作提供实际下一步；不为了填满界面放置虚假物品或“敬请期待”。
